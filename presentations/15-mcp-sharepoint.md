# Lab 14 (SharePoint): MCP SharePoint Integration

## Learning Focus
- Connect MCP tooling to SharePoint data
- Retrieve and process SharePoint resources safely
- Enable knowledge workflows on enterprise content

## Key Concepts
- SharePoint authentication flow
- Document/library querying
- Permission-aware data access

## Hands-on Walkthrough
1. Configure SharePoint credentials
2. Build MCP access tools for content retrieval
3. Query and transform documents
4. Feed results into downstream LLM workflows

## Validation Checklist
- Authentication succeeds with least privilege
- Queries respect site/library permissions
- Retrieved content is correctly normalized
