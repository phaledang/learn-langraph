# Lab 06: LangGraph Stateful Applications

## Learning Focus
- Model workflow state with `TypedDict`
- Pass data across multi-step graph execution
- Use reducers to merge state safely

## Key Concepts
- State schema design
- Node input/output contracts
- Conditional routing with state

## Hands-on Walkthrough
1. Define shared state keys
2. Implement state-transforming nodes
3. Compile and invoke graph runs
4. Inspect state transitions

## Validation Checklist
- State keys are initialized correctly
- Node updates are deterministic
- Branching logic follows expected paths
