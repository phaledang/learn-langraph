# Lab 11: MCP Integration

## Learning Focus
- Connect LangChain apps to MCP servers
- Discover server-exposed tools/resources
- Invoke MCP capabilities from agent flows

## Key Concepts
- MCP client/server roles
- Tool schemas and invocation contracts
- Resource discovery and retrieval

## Hands-on Walkthrough
1. Configure MCP connection
2. List available tools/resources
3. Bind MCP tools to an agent
4. Execute end-to-end assisted task

## Validation Checklist
- MCP server connection is stable
- Tool calls return expected payloads
- Agent behavior improves with MCP context
