# Lab 07: LangGraph Multi-Agent Systems

## Learning Focus
- Coordinate specialized agents in one graph
- Route tasks between planner and worker agents
- Aggregate intermediate agent outputs

## Key Concepts
- Agent role separation
- Orchestrator node patterns
- Message handoff between agents

## Hands-on Walkthrough
1. Define agent responsibilities
2. Add nodes for each agent role
3. Add routing edges for delegation
4. Merge final response for user output

## Validation Checklist
- Agent routing is predictable
- Handoffs preserve required context
- Final output combines all needed signals
