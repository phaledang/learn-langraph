# Lab 09: LangSmith Tracing and Monitoring

## Learning Focus
- Instrument LangChain/LangGraph executions
- Inspect traces for latency and failures
- Use metadata and tags for observability

## Key Concepts
- Runs and spans
- Prompt/response visibility
- Token and latency analytics

## Hands-on Walkthrough
1. Enable LangSmith tracing settings
2. Execute sample application runs
3. Inspect traces in dashboard
4. Identify bottlenecks and errors

## Validation Checklist
- Traces appear in the target project
- Inputs/outputs are captured correctly
- Metadata helps filter and diagnose runs
