# Lab 13: PDF and Image to CSV

## Learning Focus
- Extract structured data from PDFs and images
- Normalize extracted values into tabular schema
- Export cleaned data to CSV outputs

## Key Concepts
- OCR vs text extraction pipelines
- Field mapping and normalization
- CSV generation and data quality checks

## Hands-on Walkthrough
1. Parse source files (PDF/image)
2. Extract relevant entities
3. Normalize rows to target columns
4. Write and verify CSV output

## Validation Checklist
- Required columns are always present
- Row parsing handles malformed input
- CSV output is consistent across samples
