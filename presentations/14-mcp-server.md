# Lab 14: Building an MCP Server

## Learning Focus
- Implement custom MCP server endpoints
- Expose tools/resources with clear contracts
- Run and test server locally

## Key Concepts
- Server lifecycle and transport
- Tool/resource registration patterns
- Error reporting and logging

## Hands-on Walkthrough
1. Scaffold server configuration
2. Add resources and tools
3. Start local MCP server runtime
4. Validate calls from a client

## Validation Checklist
- Server starts and responds reliably
- Registered tools match schema contracts
- Failures return actionable errors
