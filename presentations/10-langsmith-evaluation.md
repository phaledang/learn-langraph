# Lab 10: LangSmith Evaluation and Testing

## Learning Focus
- Build repeatable LLM evaluation datasets
- Run automated evaluations for quality checks
- Track regression across prompt/model changes

## Key Concepts
- Dataset examples and references
- Evaluator functions and scoring
- Experiment comparison workflow

## Hands-on Walkthrough
1. Create or load evaluation dataset
2. Run baseline evaluation
3. Apply change and re-evaluate
4. Compare score and failure patterns

## Validation Checklist
- Evaluation jobs run successfully
- Scores are reproducible
- Regressions are clearly identified
